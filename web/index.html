接入规范

        
      

      

        导出与张量
        

          在外部完成训练，再从训练框架导出自包含 .onnx（最多 100 MB），不接受
          .pt、.pth、pickle 或外部张量文件。平台仅使用 ONNX Runtime
          CPU，不提供训练或 GPU 推理。
        

        

          恰好一个 float32 输入及一个 float 输出。输入 [B,N]（仅单导联）或
          [B,C,N]；输出 [B,K]。C、N、K
          必须对应导联数、样本数与类别数；批维为动态或固定 1。允许标准 ONNX 域及
          ai.onnx.ml。导入检查仅证明运行兼容，不证明预测性能。
        

      

      

        类别与配置字段
        

          schema_version 为 1；名称 1–80 字、版本 1–32 字、描述最多 1000
          字。classes 为 2–64 个互不重复的类别（每项最多 80
          字），顺序严格对应输出列。lead_names 为 1–12
          个有序、不重复的导联名；仅单独的 selected
          表示记录的当前分析导联，不是查看导联。采样率 100–1000 Hz，每窗口
          64–20000 个样本。不接受额外配置字段。
        

        

          任务为 beat_classification、record_classification 或
          record_multilabel；归一化 none / zscore / minmax；input_filter 为 raw
          / bandpass，notch 为 0 / 50 / 60（raw 必须为 0）；output_type 为
          logits / probabilities；多标签 threshold 严格在 0 与 1 之间。
        

      

      

        必须与训练一致的预处理
        

          输入来自完整原始 mV 样本，按配置导联顺序排列。bandpass
          在原始采样率下使用平台的三阶 Butterworth 0.5–min(40, 0.45×采样率) Hz
          带通，sosfiltfilt 零相位滤波；可选陷波为 iirnotch（Q=30）后
          filtfilt。随后以 resample_poly 对完整通道重采样，采样率比用 Fraction
          限制分母为 10000，再提取窗口。
        

        

          配置的陷波频率必须低于原始采样率的一半；无法按训练配置执行时，平台会阻止推理，不会静默跳过。
        

        

          每通道、每窗口归一化：none 保留 mV；zscore=(x−mean)/max(std,1e-6)，std
          使用总体标准差（ddof=0），均值 / 标准差以 float64
          累积；minmax=(x−min)/max(max−min,1e-6)，范围 0–1，恒定窗口为
          0。送入模型的张量为连续
          float32。训练必须使用完全相同的滤波、重采样、归一化和窗口定义。
        

        

          心搏任务围绕实际 R 峰取窗，pre_samples 为峰前样本数，须大于 0 且小于
          input_samples。边界不完整窗口跳过，不补零；要求检出可靠。记录任务只分析输入起点对应的一个固定窗口，窗口不足直接报错，不补零。
        

        

          单标签 logits 用 softmax，多标签 logits 用 sigmoid；probabilities
          需为有限的 0–1 分数，单标签每行和为 1。多标签按 threshold
          选择标签。分数是模型输出，不代表准确率或临床校准概率。
        

      

      

        结果与历史
        

          每次推理保存模型版本、配置、SHA-256、分析导联、实际窗口与运行耗时。重新分析导联、陷波或
          R
          峰改变会使旧结果过期，不能作为当前叠加；人工标注和名称修改不会改变预测。删除模型保留历史结果快照。
